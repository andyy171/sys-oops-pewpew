## Placement Rule

- Đặt ở đây khi note nói về SLO, error budget, toil, incident process, reliability target hoặc operability.
- Nếu note là alert rule, dashboard, Prometheus/Grafana config hoặc on-call runbook, đặt ở Infrastructure Automation/Observability.
