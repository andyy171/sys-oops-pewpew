# Architecture Foundations

Folder này chứa nền tảng tư duy trước khi đi vào tradeoff và pattern cụ thể. Nội dung ở đây trả lời câu hỏi: một hệ thống hiện đại nên được đóng gói, cấu hình, release và đánh giá kiến trúc như thế nào.

## Khi Tạo Note Ở Đây

- Đặt ở đây khi note là nguyên lý nền cho application/platform architecture.
- Không đặt Git command, OS administration hoặc Windows/Linux operations ở đây.
- Nếu note nói về cách đánh giá một lựa chọn kỹ thuật, ưu tiên gắn với decision framework, metric, risk và rollback.
