# Python Programming

Python là nhánh học ngôn ngữ dành cho automation, scripting, API client, data processing, test tooling và glue code trong vận hành hạ tầng. Nội dung nền tảng Python nên đặt ở đây; các workflow DevOps cụ thể bằng Python có thể được link từ [Python Automation](../../05-infrastructure-automation/05-python-automation/overview.md).

## Khi Dùng Python

- Viết script thao tác file, API, JSON/YAML/CSV, log, report.
- Tạo automation nhỏ cho vận hành, migration, audit, inventory.
- Viết API client, CLI nội bộ hoặc glue code giữa nhiều hệ thống.
- Xử lý dữ liệu vận hành: metrics export, log parse, cost/report, compliance check.
- Viết test harness hoặc tool hỗ trợ incident/debug.

## Learning Path Dự Kiến

- Python language foundations: type cơ bản, function, class, exception, module.
- Python project structure: package, virtual environment, dependency, config.
- Python files and data formats: JSON, YAML, CSV, text processing.
- Python API and CLI tooling: `requests`/HTTP client, argparse/Typer/Click.
- Python automation patterns: idempotency, dry-run, logging, retry, timeout.
- Python testing and quality: pytest, linting, type hints, fixtures.

## Ranh Giới Với Automation

- Kiến thức ngôn ngữ và pattern viết code Python đặt ở đây.
- Runbook/tool cụ thể dùng Python để vận hành hạ tầng đặt ở `05-infrastructure-automation` và link ngược lại.
