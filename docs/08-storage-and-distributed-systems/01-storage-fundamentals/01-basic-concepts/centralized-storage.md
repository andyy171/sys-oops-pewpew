# Lưu trữ tập trung 


- **DAS (Direct-Attached Storage):** Ổ đĩa gắn trực tiếp vào máy chủ.

- **NAS (Network-Attached Storage):** Thiết bị lưu trữ kết nối mạng, cung cấp File Storage (dựa trên NFS/SMB).

- **SAN (Storage Area Network):** Mạng tốc độ cao dành riêng cho việc lưu trữ, cung cấp Block Storage.
