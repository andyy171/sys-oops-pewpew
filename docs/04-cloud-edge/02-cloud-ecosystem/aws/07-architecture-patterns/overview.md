# AWS Architecture Patterns

## Overview

Nhóm này chứa các pattern thiết kế kiến trúc rút ra từ scenario thực tế và ngân hàng SAA-C03. Không nên copy câu hỏi dài vào note service; hãy chuyển thành pattern: requirement -> service choice -> reason -> caveat.

## Pattern Format

```text
Requirement -> Candidate services -> Decision -> Why -> Watch out
```

Format này giúp học AWS theo khả năng chọn kiến trúc, không chỉ nhớ tên dịch vụ.
