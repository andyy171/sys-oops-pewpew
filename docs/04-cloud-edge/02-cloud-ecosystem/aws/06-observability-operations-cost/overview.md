# AWS Observability, Operations And Cost

## Overview

Nhóm này chứa CloudWatch, CloudTrail, AWS Config, Systems Manager, Cost Explorer, Cost Anomaly Detection, Budgets và các pattern governance vận hành.

## Pages

- [CloudWatch, Config, CloudTrail And Cost](./01-cloudwatch-config-cloudtrail-cost.md)

## Mental Model

- CloudWatch đo và cảnh báo runtime state.
- CloudTrail ghi lại API activity.
- AWS Config theo dõi resource configuration và compliance.
- Cost tools đo, phân tích và cảnh báo chi phí.
- Systems Manager thường dùng để tự động hóa remediation hoặc fleet operations.
