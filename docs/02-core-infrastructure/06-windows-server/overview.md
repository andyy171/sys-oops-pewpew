# Windows Server

Folder này là nơi giữ skeleton và ghi chú tương lai cho Windows Server infrastructure. Nội dung được chuyển ra khỏi Architecture vì đây là kiến thức OS/domain operations, không phải nguyên lý system design.

## Suggested Reading

- [AD And Domain Controller](./windows-server-basics/01-active-directory-and-domain-controller.md)
- [Group Policy, Users And Roles](./windows-server-basics/02-group-policy-users-and-roles.md)
- [PowerShell Scripting](./windows-server-basics/03-powershell-scripting.md)
- [Services Management](./windows-server-basics/04-services-management.md)

## Khi Nạp Kiến Thức

- AD/Domain Controller: identity domain, forest/domain, OU, DNS dependency, replication.
- Group Policy: GPO scope, inheritance, security filtering, user/computer policy.
- PowerShell: administration automation, remoting, module, execution policy.
- Services: Windows service lifecycle, Event Viewer, dependency, recovery action.
