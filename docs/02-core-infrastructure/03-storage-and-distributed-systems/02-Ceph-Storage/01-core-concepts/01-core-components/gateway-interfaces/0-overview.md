# Tông quan về các giao diện (Gateway Interfaces) của Ceph Storage Cluster
Ceph cung cấp một nền tảng lưu trữ thống nhất trên nền tảng RADOS, cho phép truy cập dữ liệu qua nhiều giao diện khác nhau để đáp ứng đa dạng nhu cầu workload. Ceph hỗ trợ ba giao diện chính là Ceph Block Device (RBD), Ceph File System (CephFS) và RADOS Gateway (RGW). Tất cả đều được xây dựng trên nền RADOS vững chắc, kế thừa đầy đủ khả năng mở rộng tuyến tính, tính sẵn sàng cao, tự sửa lỗi và thuật toán CRUSH.

## Librados – Thư Viện Cốt Lõi Cho Truy Cập Trực Tiếp Vào RADOS
- Librados là thư viện C++ cung cấp khả năng truy cập trực tiếp vào lớp RADOS của Ceph Storage Cluster. Nhờ đó, ứng dụng có thể lưu trữ và lấy object mà không cần qua bất kỳ giao diện cấp cao nào. Librados xây dựng nên một nền tảng mạnh mẽ, có khả năng mở rộng cao và hiệu năng vượt trội, tận dụng tối đa sức mạnh của RADOS mà không làm giảm tốc độ. 

- Thư viện này hỗ trợ mở rộng tới quy mô exabyte và tương thích cao với nhiều ngôn ngữ lập trình như C, C++, Python, Java và PHP. Nguyên tắc cơ bản của librados là mở rộng thành phần, chịu lỗi cao, dựa trên phần mềm mở và khả năng thích nghi linh hoạt. Librados quản lý object, thực hiện nhân bản toàn cluster và nâng cao mức độ bảo đảm dữ liệu. Các object không có đường dẫn vật lý cố định nên có thể linh hoạt mở rộng từ petabyte lên exabyte.

- Khối lượng dữ liệu toàn cầu tăng 40-60% mỗi năm, dẫn đến những thách thức lớn về tính thống nhất, phân tán và hiệu năng. Librados nổi bật như một giải pháp vượt trội nhờ tính thống nhất, khả năng phân phối và chi phí hợp lý. Nó tích hợp sâu với kernel, hỗ trợ tốt cho các môi trường cloud như OpenStack và Kubernetes. Các đội ngũ Canonical, Red Hat, SUSE đã cùng hoàn thiện librados, mang lại mức độ tương thích cao trên Linux. 

- Librados là giải pháp software-defined storage thực thụ, giúp tiết kiệm chi phí, hỗ trợ phần cứng đa dạng và mang lại lợi thế về chi phí thấp, độ tin cậy cao cùng khả năng mở rộng. Nó cung cấp truy cập object-based thống nhất, đáp ứng tốt nhu cầu tăng trưởng dữ liệu. Kiến trúc mới của librados không sử dụng metadata trung tâm mà thay vào đó dùng CRUSH để tính toán vị trí dữ liệu động. Nhờ đó tốc độ được cải thiện đáng kể, mọi thứ được phân tán hoàn toàn trên các node. CRUSH nhận thức rõ hạ tầng (disk, pool, node, rack, data center), tự động sửa lỗi và nhân bản dữ liệu. Hệ thống hỗ trợ atomic transaction và inter-client communication, giúp tăng performance và reliability cho các nền tảng PaaS/SaaS.

- Librados dẫn đầu công nghệ truy cập mới, vượt qua giới hạn của các giải pháp truyền thống. Nó mang tính mở, software-defined và linh hoạt cao, thống nhất object access, phù hợp với cả small data lẫn big data. Hệ thống tự quản trị và tự sửa lỗi trên disk, node, network, rack hay data center.

## Ceph Block Device (RBD) – Giao Diện Lưu Trữ Block
- **RBD (Ceph Block Device)** là giải pháp block storage phân tán, hiệu năng cao và chịu lỗi vượt trội của Ceph. RBD được thiết kế để đáp ứng nhu cầu lưu trữ phân tán, mở rộng cao, hỗ trợ dung lượng lên tới exabyte và tương thích hoàn hảo với các nền tảng ảo hóa như KVM, VMware, OpenStack hay CloudStack. 
- RBD chia block thành nhiều object và phân tán chúng toàn bộ cluster, mang lại tính bảo đảm và hiệu năng cao. Nó hỗ trợ image size lên tới 16EB, tích hợp chặt chẽ với Linux kernel driver và cung cấp nhiều tính năng quan trọng như snapshot tốc độ cao, copy-on-write cloning, thin provisioning cùng dynamic resize. Ngoài ra RBD còn hỗ trợ in-memory caching để nâng cao hiệu năng đáng kể.
- Nguyên tắc cốt lõi của RBD bao gồm khả năng mở rộng thành phần, chịu lỗi cao, dựa trên phần mềm mở và thích nghi tốt với mọi loại phần cứng. Toàn bộ RBD dựa trên object RADOS nên không phụ thuộc vào metadata trung tâm. So với block storage truyền thống, RBD có ưu thế vượt trội vì không cần metadata server trung tâm gây độ trễ cao khi scale lớn. Thay vào đó RBD sử dụng CRUSH để tính toán vị trí dữ liệu động, mang lại tốc độ cao, phân tán hoàn toàn và khả năng tự sửa lỗi trên disk, node, network, rack hay data center.
- Một số tính năng nổi bật của RBD gồm snapshot & clone,** mirroring (journal-based hoặc snapshot-based)**, **exclusive-lock**, **object-map**, **fast-diff**, **erasure coding** và **NVMe-oF**.

## CephFS – Ceph File System
- CephFS là hệ thống file POSIX-compliant phân tán, cho phép nhiều client truy cập đồng thời vào cùng một không gian lưu trữ. CephFS rất phù hợp với các workload truyền thống như home directories, shared storage, kho lưu trữ hoặc các ứng dụng HPC cần filesystem dùng chung.
- CephFS lưu dữ liệu và metadata riêng biệt (data pool và metadata pool) để tối ưu hiệu năng và độ tin cậy. Client có thể mount CephFS thông qua Linux kernel driver hoặc ceph-fuse (filesystem in user space). Ngoài ra còn có thể sử dụng phần mềm thứ ba như Ganesha cho NFS và Samba cho SMB/CIFS. CephFS cũng tích hợp tốt với Hadoop (HDFS) thông qua libcephfs.
- Thành phần quan trọng nhất của CephFS là MDS (Metadata Server) – chịu trách nhiệm quản lý metadata như cấu trúc thư mục và quyền truy cập. CephFS hỗ trợ multiple MDS theo mô hình active/standby để tăng khả năng chịu lỗi và scale.
- Các tính năng chính của CephFS gồm snapshots, multiple filesystems support cùng sự phân biệt rõ ràng giữa data pool và metadata pool. CephFS cũng hỗ trợ các tính năng như POSIX ACLs, extended attributes, và tích hợp với các công cụ quản lý dữ liệu như Hadoop. CephFS là giải pháp lý tưởng cho các ứng dụng cần filesystem dùng chung với khả năng mở rộng cao và độ tin cậy vượt trội.

## RADOS Gateway (RGW) – Giao Diện Lưu Trữ Object
- RGW (RADOS Gateway) là object storage gateway cung cấp giao diện RESTful tương thích hoàn toàn với Amazon S3 và OpenStack Swift. Đây là giải pháp lý tưởng cho việc lưu trữ dữ liệu phi cấu trúc, media, backup, cloud-native applications và đặc biệt là multi-site replication.
- RGW sử dụng librgw kết hợp với librados để cho phép ứng dụng kết nối trực tiếp với Ceph cluster. Nó cung cấp ba loại interface chính: S3 compatibility, Swift compatibility và Admin API. Nhờ kiến trúc true object-based storage, RGW không cần filesystem hay block layer trung gian.
- Các tính năng nổi bật của RGW gồm multi-site replication (zones, zonegroups, realms), bucket policies & lifecycle cùng indexless buckets.
