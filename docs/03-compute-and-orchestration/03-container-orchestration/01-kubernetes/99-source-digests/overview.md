# Kubernetes Source Coverage Records

## Overview

Thư mục này chỉ nên đóng vai trò source coverage/audit cho các tài liệu lớn về Kubernetes. Learning path chính của Kubernetes nằm trong các folder canonical `00-architecture` đến `10-advanced` và `98-troubleshooting`.

Trạng thái hiện tại: một số note trong thư mục này vẫn còn dài và giữ hình dạng của tài liệu nguồn. Các note đó cần được canonicalize: bóc knowledge atom, merge vào canonical notes, rồi thay bằng coverage matrix ngắn.

Vai trò đúng của thư mục này:

- ghi tài liệu nguồn là gì;
- ghi phần nào đã đọc/xử lý;
- map knowledge atom sang canonical destination;
- ghi status: merged, skipped, deferred, superseded;
- giữ caveat/modernization note về nguồn.

Không dùng thư mục này như note học Kubernetes song song.
